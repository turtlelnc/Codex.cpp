# 对话优先的 WebUI 改造

保留已有米白、暖色和中文界面，在现有 HTML/CSS、原生 JavaScript 与 C++17 RPC 上做局部调整。未引入前端框架或应用构建依赖。

## 实际确认的问题

| Before | After | 原因与处理 |
| --- | --- | --- |
| 检查器初始占用 440px | 首次打开默认关闭，宽屏按需分栏，中小窗口覆盖工作区 | 原默认状态和固定列宽压缩了对话；阅读宽度设为 740px |
| 项目文件一直占据侧栏 | 会话导航为主，原生 details 折叠文件树 | 保留全部查看、编辑、保存和冲突检测流程 |
| 窄屏检查器覆盖对话，但遮挡控件仍可 Tab 聚焦 | 遮挡期间 conversation.inert；关闭和 Esc 恢复焦点 | 保留可见的导航、顶栏与面板操作；移动侧栏保留遮罩、焦点循环 |
| Esc 关闭菜单时也可能关闭检查器 | 按事件处理顺序只关闭当前层 | 避免多个 document 键盘监听器同时响应 |
| 文件树普通 div 仅支持点击 | 原生按钮，刷新后恢复文件/目录焦点和树滚动 | 保留目录展开状态与键盘操作 |
| 连续工具各自堆成卡片 | 连续调用汇总为可展开记录，内部为紧凑列表 | 复用工具 DOM 与 details 状态；不根据工具名推测 Agent 的意图 |
| 无结果一律视为运行中，负退出码未被识别 | 使用真实 tool.started/completed 事件及退出码；缺少证据时显示等待结果/已返回 | 失败、拒绝、中断单独呈现；历史记录不宣称未知执行结果成功 |
| 补丁审批触发打开检查器 | 对话内保留补丁预览和批准/拒绝，检查器由用户打开 | 权限、审批 ID 和补丁应用逻辑不变 |
| 参数/输出快照截断却没有原始日志入口 | 显示截断标记，按需读取当前会话保存的完整日志 | 快照仍轻量；完整参数和结果通过只读 RPC 获取 |
| 模型控件多层紧凑规则覆盖 | 把最终值合并到组件定义，布局媒体查询集中 | 保持已有菜单外观，删去已被覆盖的旧值 |

## 状态与渲染

连续工具调用只按实际时间顺序分组，遇到用户消息、Agent 回复或待审批调用就结束该组。摘要只统计调用状态，不声称读取了多少文件、找到了多少问题。等待授权的调用独立显示，不藏在折叠组内。

历史消息和工具节点按现有内容缓存复用，分组节点单独按首个调用保持身份。刷新前记录可见消息锚点；阅读历史时恢复锚点位置，接近底部时跟随新消息。工具结果到达而替换卡片时，恢复原工具标题的键盘焦点。保留现有保存修订号、请求失效检查、发送幂等和轮询恢复机制。

流式草稿保留同一个消息节点及未变化的 Markdown 节点，对整批新增文字按字素分成最多 16 个片段做 140ms 淡入及 1px 模糊，片段同时开始且从 35% 可见度起步；超过 4096 字符的单批内容使用一个片段；结束后合并为普通文本。不创建逐帧 JavaScript 循环、逐字定时器或常驻 will-change。阅读历史、选中文字、后台标签页和系统“减少动态效果”模式下跳过动画；更改减少动态效果偏好会关闭并清理动画（选中动画文字时延迟合并节点，以保护选区）。等长改写和 Markdown 结构变化不会重播旧正文。

默认检查器关闭；新布局使用独立的 `codex.layout.v2` 偏好，避免旧版自动存下的“默认打开”覆盖新默认。用户之后明确选择的桌面面板状态仍会记忆。窄屏状态在页面内独立维护。

设备登录继续读取认证进程的 login.notice。修复了提供商按钮启动登录后再次打开提供商弹窗、遮住登录窗口的问题；不触发模型请求。

## 新增只读 RPC

`tool_log` 请求包含当前 `session_id` 和 `call_id`，返回 `name`、原始 `arguments` 及 `output`（尚未保存结果时为 null）。仅扫描当前 App 在当前工作区的会话日志。服务器已有成员鉴权、个人/共同作用域、CSRF 与文件边界继续生效；会话变更或找不到调用时报错。

快照的工具行增加 `args_truncated` / `output_truncated`，不改变已有字段。完整日志弹窗通过 textContent 展示原始文本。

## 验证

- `tests/webui_quality_test.cjs`：真实 Linux Chromium，可控延迟/失败响应；覆盖侧栏、检查器和断点，保存竞态，乱序文件/会话/项目响应，600 条消息的节点/选择/滚动，等长草稿变化、审批重试与补丁拒绝、负退出码与中断、完整日志、面板焦点、移动侧栏键盘循环、1200 行 Diff、200 次调用突发及模拟设备登录。
- 缩放相关测试用 CDP 模拟 80% / 125% / 200% 对应的 CSS 视口和 DPR，验证溢出和输入区位置；不等同于手动操作浏览器工具栏缩放。
- `tests/native_smoke.cjs`：真实 C++ 文件保存、冲突、CSRF、Host、账户流程；新增超过预览限制的原始参数/日志读取、截断标记以及旧会话/缺失调用拒绝。
- `tests/native_web_test.cjs`：在已配置 OS 沙箱的集成环境中验证完整日志的共同/个人作用域、不同用户隔离及非成员拒绝；基础冒烟测试不创建 Git 工作区，继续保持无沙箱依赖。
- `tests/native_browser_test.cjs` 与 `tests/team_browser_test.cjs`：真实 C++ 服务上的编辑、模型、Agent 审批写入和团队设置/个人任务。

浏览器测试使用本地假模型，不消耗模型额度。运行方式沿用 [WebUI 质量验证](WEBUI_QUALITY.md)，不改变用户运行软件的依赖。

## 已知边界

未在 Safari、Firefox、实体触屏设备、屏幕阅读器或真实浏览器工具栏缩放中验证。保留既有最近 400 条 journal 行快照上限，未实现历史分页或虚拟列表；600 条浏览器记录测试是前端压力夹具，不代表后端已取消该上限。完整日志指实际持久化的工具记录，不能恢复工具运行阶段本来就未采集的输出。完整历史仍在工作区的会话文件中。

## 思考内容与动画修订

| 修改前 | 修改后 |
| --- | --- |
| reasoning_content 被忽略 | 真实返回的思考增量显示在原生 details 折叠区，完成后写入会话并可刷新恢复 |
| 新增正文前部立即出现，仅末尾淡入 | 整批新增文字参与渐显，仍限制最多 16 个动画片段 |
| 忙碌时每 400ms 拉取快照 | 每 200ms 拉取，继续串行等待，避免重叠请求 |

新增 model.reasoning.delta 事件、reasoning_draft 快照字段和 reasoning journal 行。只展示提供商实际返回的 reasoning_content 或 Codex reasoning text/summary 事件，不推测未公开的推理内容。思考记录不作为 Responses 输入；Chat 工具调用保留同一轮 reasoning_content，以支持 DeepSeek 工具续接。正文、审批与权限语义保持原样。

流式光标锚定最后一个实际文字叶节点，避免 pre/list 等容器将光标放到段落后。取消片段排队延迟，新增文字立即以较浅颜色出现，不再预留完全透明的后续文字；仍使用既有每 200ms 忙碌快照轮询，模型及网络延迟不会被前端掩盖。
