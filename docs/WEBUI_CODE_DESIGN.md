## 工具间思考记录

服务端实际返回的 reasoning 记录可以与连续工具调用处于同一分组，并保持原始时间顺序。每段思考单独折叠，分组摘要标注段数，但不把 reasoning 算作命令。首次工具之前的思考及正在流式生成的 reasoning 保持原有显示位置；待审批调用仍独立显示。没有返回 reasoning 的提供商不会生成占位思考或推测文本。展开状态在执行状态更新后保留。


## 动态过渡

工具分组、思考记录和单次工具详情使用约 180ms 的真实高度过渡，透明度与状态文字使用约 140ms 的淡入。展开内容立即可交互，收起时延后隐藏内容以完成过渡；不延后审批或网络操作。支持 `interpolate-size` 的浏览器启用高度过渡，其他浏览器保留即时折叠。系统“减少动态效果”下关闭这些过渡及状态文字动画。浏览器测试采样展开/收起的中间高度，并检查键盘操作与减少动态效果。
